아산시립도서관 책 찾기 - 최종 개발판

1) 최종 사용자는 Python이 필요 없습니다. 완성된 AsanLibraryFinder.exe만 실행합니다.
2) 이 패키지에서 EXE를 직접 만드는 PC는 Windows + Python이 필요합니다.
3) EXE 만들기: Python 3.11 이상 설치 -> build_exe.bat 더블클릭 -> dist\AsanLibraryFinder.exe 생성

주요 기능
- 아산시립도서관 DLS 통합검색 실시간 조회
- 제목 여러 개를 한 번에 검색
- 실제 DLS 검색 결과의 도서명/저자/발행처/발행년/청구기호/소장기관/자료실/대출상태 추출
- 상세 소장정보에서 등록번호/낱권/반납예정일 추출
- 대출가능 자료와 대출중/기타 자료를 별도 탭으로 표시
- 탕정면 기준 도서관까지의 직선거리(km)를 계산하여 대출가능 자료 안에서 가까운 순으로 정렬
- 상호대차 신청가능 여부 표시
- 딸림자료가 상세 페이지에 실제 표시될 경우 추출
- Excel 저장: 전체결과 / 대출가능 / 대출중_기타 3개 시트

검증
- 제공된 아산 DLS 실제 검색결과 HTML과 상세 HTML을 대상으로 오프라인 파싱 테스트를 통과했습니다.
- 샘플 검색결과 6건, 대출가능 5건, 상세 등록번호 UM0000019068, 반납예정일 2026-10-31을 확인했습니다.

주의
- 현재 환경에서는 lib.asan.go.kr 실시간 접속을 직접 실행할 수 없어 실시간 네트워크 검색은 별도 검증이 필요합니다.
- 거리(km)는 도로 주행거리가 아니라 좌표 기반 직선거리입니다.
- 사이트 HTML 구조가 바뀌면 파서 수정이 필요할 수 있습니다.
